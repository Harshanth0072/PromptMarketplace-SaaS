# PromptForge 🔥 — AI Prompt Marketplace SaaS

**Unique Complex Money-Making Project**

A full-featured marketplace where AI enthusiasts and creators **buy and sell high-quality prompts**. Platform takes a commission on every sale — classic two-sided marketplace model that scales to serious revenue.

## Why this makes money

- **Platform fee**: 15-30% on every prompt sale
- **Subscriptions**: Premium seller accounts, featured listings, analytics
- **Featured placements**: Sellers pay extra for homepage / category boosts
- **API access**: Charge agencies for bulk prompt access

Many prompt marketplaces already do $10k–$100k+/month. This is a production-ready foundation you can launch.

## Features

### Buyer Side
- Beautiful prompt discovery with categories, tags, search
- Detailed prompt pages with previews, ratings, sales count
- One-click purchase flow (Stripe ready)
- Personal library of purchased prompts

### Seller Side
- Upload & manage prompts
- Real-time earnings dashboard
- Sales analytics & conversion metrics
- Payout requests

### Platform
- Modern dark UI (Next.js 15 + Tailwind)
- Fully typed TypeScript
- Responsive + mobile friendly
- Mock data + realistic flows
- Ready for auth, database, Stripe Connect

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React
- Recharts (seller analytics)
- Framer Motion ready
